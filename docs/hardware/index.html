    Common questions

    Is it better to buy or rent?

    Rent to start fast and test demand. Buy when load is steady and data cannot leave your perimeter.

    Do you manufacture servers?

    No. We supply to order through partners and handle sizing, set-up and launch.

    Can you use hardware we already own?

    Yes. We check the configuration and deploy the model on it.
