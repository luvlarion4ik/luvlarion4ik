# Growth Map AI server

Small HTTP service behind «Карта роста». The browser sends the brief (without the business name and contacts),
the server asks the model at [CLODEX](https://clodex.xyz/docs) (OpenAI-compatible API) and returns a cleaned answer:
block changes from the catalog only, sales texts with `{placeholders}` instead of numbers. The site fills the
placeholders with its own calculation, so the texts always match the table. The API key never reaches the browser.

No npm packages. Node.js 22 or Cloudflare Workers.

| File | What it is |
| --- | --- |
| `handler.mjs` | All logic: routes, CORS, limits, provider call, retries |
| `prompts.mjs` | System prompts (sales persona, catalog, guarantees, reviews) |
| `validate.mjs` | Cleaning of model answers |
| `data.mjs` | Catalog, guarantees and reviews. Generated by `npm run build`, do not edit |
| `server.mjs` | Entry for a VPS |
| `worker.mjs`, `wrangler.toml` | Entry for Cloudflare Workers |
| `deploy/` | systemd unit and nginx snippet |
| `.env.example` | Settings template |

## Endpoints

- `GET /health` → `{ ok, configured, model }`
- `POST /parse` `{ lang, text }` → `{ brief }` (20 per IP per hour)
- `POST /analyze` `{ lang, brief, variants, economy }` → `{ headline, reasons, variants, gaps, objections }` (6 per IP per hour)

All POST requests need an `Origin` listed in `ALLOWED_ORIGINS`. `DAILY_LIMIT` caps paid requests per day (default 400).
Limits live in memory: they reset on restart and, on Workers, per isolate.

## Settings (`.env` next to `server.mjs`, or environment variables)

| Name | Meaning |
| --- | --- |
| `CLODEX_API_KEY` | Key from the CLODEX dashboard. Required |
| `GM_MODEL` | Exact model id of GPT Sol 6.2 as `npm run ai:check` prints it. Required |
| `CLODEX_BASE_URL` | `https://clodex.xyz/v1` |
| `ALLOWED_ORIGINS` | Site origins, comma-separated, e.g. `https://luvlarion4ik.github.io` |
| `PORT`, `HOST` | `8787`, `127.0.0.1` |
| `DAILY_LIMIT` | `400` |
| `TIMEOUT_MS` | `25000` |

## Run on a VPS

```sh
git clone https://github.com/luvlarion4ik/luvlarion4ik.git /opt/devlarion
cd /opt/devlarion/server/growth-map
cp .env.example .env        # put CLODEX_API_KEY into .env
node server.mjs --check     # lists models; put the GPT Sol 6.2 id into GM_MODEL, run again until "OK"
node server.mjs             # quick manual start; then install deploy/devlarion-growth-map.service
```

Put `deploy/nginx.conf` into the HTTPS server block, reload nginx, then:

```sh
curl https://YOUR_DOMAIN/gm-ai/health
curl -i -X OPTIONS https://YOUR_DOMAIN/gm-ai/analyze -H 'Origin: https://luvlarion4ik.github.io'
curl -s https://YOUR_DOMAIN/gm-ai/parse -H 'Origin: https://luvlarion4ik.github.io' -H 'content-type: application/json' \
  -d '{"lang":"ru","text":"Барбершоп в Казани, 3 мастера, клиенты из Яндекс Карт, записываем в директе, чек 1800"}'
```

## Run on Cloudflare Workers instead

```sh
cd server/growth-map
npx wrangler login
npx wrangler secret put CLODEX_API_KEY
# set GM_MODEL and ALLOWED_ORIGINS in wrangler.toml
npx wrangler deploy
```

The endpoint is then `https://devlarion-growth-map.<account>.workers.dev`.

## Turn it on for the site

In `content/site.json` set `growthMap.ai` to `"on"` and `growthMap.endpoint` to the HTTPS address without a trailing slash
(or use `npm run admin`, tab «Карта роста»). Then `npm run build`, `npm run check`, commit and push.
Turning `ai` back to `"off"` returns the site to the built-in engine; nothing else changes.

## Tests
