# Обновление Devlarion

Для сборки нужен Node.js 22. Дополнительные пакеты не требуются.

- npm run admin открывает редактор на http://127.0.0.1:4174. Он сохраняет данные в content/site.json и пересобирает docs/.
- npm run build обновляет HTML, README и sitemap.
- npm run check сверяет сохранённую сборку с исходниками.

В редакторе можно задать цены, статус готовых решений, курс валют с датой, реквизиты ИП, условия реферальной программы, материалы о команде и тексты кейсов. Курс BYN вносится в рублях за 1 BYN, курс KZT в рублях за 100 KZT. Источник — [Банк России](https://www.cbr.ru/currency_base/daily/).

Перед публикацией участника добавьте имя, роль и дату согласия. Портрет можно положить в docs/assets/team/ и указать путь вида team/ilya.webp. Личные достижения добавляются со ссылкой на именной результат. Реквизиты, портреты и опубликованные источники появятся в публичном GitHub Pages после сборки. После правок проверьте git diff и опубликуйте исходники и сгенерированные файлы вместе.

## Реферальные заявки

Калькулятор передаёт код из ссылки или из формы в черновик Telegram. Проверка первой заявки, договора, оплаты и права на скидку ведётся владельцем. Журнал сохраняется локально в .devlarion-referrals.json. Указывайте внутренние идентификаторы проектов и заказчиков.

    npm run referrals -- issue PROJECT_ID
    npm run referrals -- claim CODE CUSTOMER_ID
    npm run referrals -- confirm CODE
    npm run referrals -- apply CODE referrer
    npm run referrals -- apply CODE customer
    npm run referrals -- list

Команда issue возвращает ссылку, которую можно отправить клиенту для рекомендации. Используйте claim для первой заявки нового клиента. Выполняйте confirm после оплаты первого этапа. Перед apply согласуйте, на какие работы действует скидка, и проверьте общий потолок скидок по договору. Журнал фиксирует условия, действовавшие при выдаче кода.
