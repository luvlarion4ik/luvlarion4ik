# Карта роста · T8

Проверено в Chrome 158 на macOS, WebKit 26.5 и Firefox 151. В Chrome также пройден мобильный сценарий 375 × 812 с эмуляцией касаний. В проверки входили поля формы, кнопки и ссылки реальных страниц сборки.

| Проверка | Результат |
| --- | --- |
| Пять брифов вручную | В Chrome графы совпали с фикстурами целиком, включая состав узлов и связей. |
| Три текста-примера | Русские и английские примеры определили нишу. Распознанные поля подсвечены. |
| Анализ и варианты | Сцена заняла около 5,0 с. Пропуск работает. Результат открывается на «Ускорении» со вкладкой «Сравнение». Переключение вариантов, список и выход из 3D по Escape проверены. |
| Стоимость и внешний вид | USD и KZT пересчитывают суммы на панели и в сравнении. Сцена остаётся тёмной в Авто, Меди, Тёмно-синей и Шалфее. |
| Мобильный сценарий | Пройдены панорамирование одним пальцем, щипок, долгое нажатие для перемещения и три положения панели. Ширина страницы 375 px. |
| Сохранение | Пройдены возврат после перезагрузки, открытие общей ссылки в отдельном контексте, скачивание и импорт JSON, ошибка повреждённого файла, сохранение, открытие и удаление в кабинете. |
| Telegram | Русский и английский черновики в Chrome и русский в WebKit перехвачены локально. Ссылки из текстов открыли карты. Сообщения не отправлялись. |
| Клавиатура и движение | Шесть шагов формы пройдены с клавиатуры. При reduced motion зафиксировано 0 активных анимаций после появления карты. На 1440 × 900 прокручивается только шаг 4. |
| Хранилище | При эмуляции отказа localStorage карта строится и показывает предупреждение. |
| Автоматическая проверка доступности | Lighthouse 13.5.0 оценил доступность начального состояния русской карты на 100/100. Axe в Chrome и WebKit не нашёл нарушений WCAG 2 A/AA в выборе режима, первом шаге брифа, сравнении, списке и библиотеке. |
| Консоль | Ошибок в описанных сценариях не зафиксировано. |

В приватном окне Safari 27.2 на macOS открылись русская страница и режим описания. Парсер определил сферу, направление и модель продаж в примере барбершопа. Полный сценарий прошёл в Playwright WebKit. Полный ручной прогон в Safari и чтение списка в VoiceOver остаются непроверенными.

Chrome на Apple M5 записал 171 кадр за 2,83 секунды при перетаскивании на холсте с 30 узлами и 55 связями. При 375 px холст занимает 60% высоты окна, а сравнение прокручивается внутри панели. Тизер проверен на ширинах 375, 768 и 1440 px во всех четырёх темах.
