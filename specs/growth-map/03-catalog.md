## 5. Блоки

Поля блока в `gm-catalog.js`:

```js
{
  id: 'cap_quiz',            // уникальный, префикс по этапу
  stage: 'capture',
  icon: 'quiz',
  title: { ru: 'Квиз-калькулятор', en: 'Quote quiz' },
  benefit: { ru: '…', en: '…' },          // строка пользы в библиотеке и инспекторе
  fx: { t:0, leak:0, conv:0.12, check:0, repeat:0, hours:0 },  // эффекты, см. 04-engine.md
  service: 'web', share: 0.3,              // услуга из content/pricing.mjs estimator и доля её цены, либо service: null
  tier: 2,                                 // минимальный вариант: 1 base, 2 boost, 3 auto
  when: { models: [...], categories: [...], sizes: [...], cycle: [...], pains: [...], wishes: [...], minCheck: 15000 }, // условия подбора, все необязательные
  next: ['proc_crm', 'proc_notify'],       // предпочтительные цели связей
  replaces: ['cap_form'],                  // какие блоки этот вытесняет в том же варианте
  settings: 'paymentProvider'              // ключ набора настроек из раздела 6, если есть
}
```

Иконки блоков из таблиц 5.1–5.7 агент T1 назначает сам: короткое английское имя по смыслу (`calendar` для записи, `bell` для уведомлений, `card` для эквайринга, `receipt` для чеков, `bot` для ботов, `phone-app` для приложения, `gift` для бонусов, `chart` для аналитики и т. д.), одна иконка может служить нескольким блокам. Существующие `docs/assets/icons/*.svg` (`web`, `mini`, `bot`, `mobile`, `ai`, `server`, `layers`, `support`, `design`, `mail`, `telegram`) используются под своими именами. Итоговый список имён передаётся в T3.

Расшифровка эффектов `fx`:
- `t` — прирост потока обращений (доля);
- `leak` — во сколько раз меньше теряется заявок (доля сокращения потерь, 0.4 = потерь на 40% меньше);
- `conv` — относительный рост конверсии из обращения в оплату;
- `check` — относительный рост среднего чека;
- `repeat` — абсолютная прибавка к доле повторной выручки;
- `hours` — часов ручной работы в месяц, которые блок забирает на себя (для формата «команда до 10», масштабируется в движке).

Размеры (`sizes`): `solo` — работаю один, `team` — до 10 человек, `mid` — 10–50, `large` — больше 50. Цикл (`cycle`): `day`, `week`, `month`, `long`. `minCheck` — средний чек в рублях не ниже порога.

Условия `when`: блок подходит, если выполнены все указанные условия, а внутри одного условия достаточно одного совпадения. `wishes` в `when` поднимает блок на вариант ниже (если пользователь сам хочет мобильное приложение, оно появится уже в «Ускорении»).

## 7. Связи по умолчанию (`next`)

Если у блока нет поля `next`, связь идёт ко всем блокам следующего непустого этапа, но не больше трёх (первые три по порядку колонки). Петля возврата: каждый блок `retain` с `t > 0` или `ret_referral` соединяется дугой `kind: 'loop'` с первым блоком `entry`. Блоки `insight` соединяются пунктиром `kind: 'data'` с `proc_crm` (или первым `process`) и первым `pay`.

Готовые предпочтения, которые агент каталога вписывает явно:
- `cap_*` → `proc_crm`, `proc_notify`, `proc_table`;
- `proc_*` → `pay_acq`, `pay_link`, `pay_invoice`, `pay_prepay`;
- `pay_acq`, `pay_link` → `pay_receipt` (внутри этапа, короткая связь вниз), затем → первый `deliver`;
- `del_*` → `ret_review`, `ret_broadcast`, `ret_loyalty`;
- `ent_tgbot` → `cap_booking` (если есть), иначе `cap_form`, иначе первый `capture`.
