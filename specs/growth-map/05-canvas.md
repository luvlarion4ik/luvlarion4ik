# 05. Холст

Файл `docs/assets/growth-map/gm-canvas.js`, стили в `docs/assets/growth-map/growth-map.css`. Без библиотек. Задача: ощущение дорогого конструктора уровня Figma/Linear, а не «сайта с картинками».

## 1. Структура DOM

```html
<div class="gm-stage" data-gm-stage tabindex="-1">           <!-- окно просмотра, overflow hidden, perspective -->
  <div class="gm-bg" aria-hidden="true"></div>               <!-- сетка точек и виньетка, двигается с параллаксом -->
  <div class="gm-world" data-gm-world>                       <!-- transform: translate(x,y) scale(z) -->
    <div class="gm-lanes" aria-hidden="true">…</div>         <!-- полосы этапов с заголовками -->
    <svg class="gm-edges" aria-hidden="true">…</svg>         <!-- связи, частицы, маркеры потерь -->
    <div class="gm-nodes" role="list" aria-label="Схема">    <!-- узлы -->
      <div class="gm-node" role="listitem" tabindex="0" data-node="n1" data-stage="capture">…</div>
    </div>
  </div>
  <div class="gm-minimap" aria-hidden="true"></div>          <!-- 160×100, правый нижний угол холста -->
  <div class="gm-hud">…</div>                                 <!-- сцена анализа, пустое состояние, подсказки -->
</div>
```

SVG связей имеет размер мира (по крайним узлам + запас 400 px) и лежит в том же трансформированном слое, что и узлы, поэтому координаты связей совпадают с координатами узлов без пересчёта.

## 2. Визуальный язык

### 2.1. Сцена

- Фон сцены всегда тёмный, в любой теме сайта: `background: radial-gradient(120% 80% at 50% 0%, color-mix(in oklab, var(--night) 70%, var(--accent) 8%), var(--night))`. Сайт в светлой теме вокруг, холст — «экран прибора». Это и делает вид премиальным.
- Сетка точек: `background-image: radial-gradient(circle, rgb(255 255 255 / .07) 1px, transparent 1.2px)`, шаг 24 px × масштаб, сдвиг с миром.
- Виньетка по краям: `box-shadow: inset 0 0 160px rgb(0 0 0 / .45)`.
- Полосы этапов: колонки шириной 248 px, фон `rgb(255 255 255 / .02)`, сверху заголовок этапа (12 px, uppercase, разрядка .08em, цвет этапа с прозрачностью .8) и подпись (12 px, `rgb(255 255 255 / .45)`). Тонкая линия цвета этапа 2 px сверху колонки.
- Шрифт интерфейса холста — Golos Text, как на сайте. Цифры экономики — Golos Text с `font-variant-numeric: tabular-nums`.

### 2.2. Узел

Размер 216 × 72 (компактный 216 × 56). Структура:

```
┌──────────────────────────────────────────┐
│ ▣  Онлайн-запись                     ◦→ │  ▣ — плитка иконки 40×40, градиент цвета этапа
│    Клиент выбирает время сам     +15%    │  чип эффекта справа внизу
└──────────────────────────────────────────┘
 ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔  «толщина» 6 px — объём
```

- Фон: `rgb(255 255 255 / .06)` + `backdrop-filter: blur(12px)`, рамка `1px solid rgb(255 255 255 / .10)`, радиус 14 px.
- Объём: псевдоэлемент `::after` под карточкой, `transform: translateY(6px)`, тот же радиус, цвет `color-mix(in oklab, <цвет этапа> 35%, black)`, `z-index: -1`. Тени: `0 1px 0 rgb(255 255 255/.08) inset, 0 10px 30px -10px rgb(0 0 0/.6), 0 2px 6px rgb(0 0 0/.3)`.
- Плитка иконки: градиент `linear-gradient(135deg, <цвет этапа>, color-mix(in oklab, <цвет этапа> 60%, black))`, иконка белая 22 px, внутренняя подсветка сверху.
- Заголовок 14 px / 600, `#f2f0ea`. Подзаголовок 12 px, `rgb(255 255 255 / .55)`, одна строка с многоточием.
- Чип эффекта: 11 px, фон `rgb(255 255 255 / .08)`, текст — главный эффект блока (порядок приоритета: `t` «+18% клиентов», `leak` «−30% потерь», `conv` «+15% к продажам», `repeat` «+8% повторных», `check` «+10% к чеку», `hours` «−20 ч/мес»).
- Порты: справа выход, слева вход, кружки 10 px, видимы при наведении и при перетаскивании связи. Цвет этапа.
- Блок из «Как сейчас», который в варианте остался: маленькая метка «было» в правом верхнем углу.
- Новый блок относительно «Как сейчас»: метка «новое» цвета акцента, только при первом показе варианта (исчезает через 3 с).
- Состояния:
  - hover: `transform: translateZ(18px) rotateX(var(--rx)) rotateY(var(--ry))`, где `--rx/--ry` до ±6° за курсором (обновлять через `requestAnimationFrame`), объём под карточкой растягивается до 10 px;
  - selected: кольцо `0 0 0 2px var(--accent)` + свечение `0 0 24px color-mix(in oklab, var(--accent) 45%, transparent)`;
  - dragging: `translateZ(30px) scale(1.03)`, тень больше, курсор `grabbing`, у остальных узлов `opacity .85`;
  - orphan (без связей): пунктирная рамка, мерцание прозрачности .6–1 раз в 2 с;
  - в варианте «Как сейчас» узлы с потерями имеют красную точку в углу.

### 2.3. Связи

- Кубическая кривая Безье от порта к порту: `M x1 y1 C x1+dx y1, x2−dx y2, x2 y2`, `dx = max(60, |x2−x1| × 0.45)`.
- Слой связи состоит из трёх путей: подложка (ширина 6, цвет этапа источника, прозрачность .08), основная линия (ширина 2, градиент от цвета этапа источника к цвету этапа цели через `<linearGradient gradientUnits="userSpaceOnUse">` по координатам концов), анимированный пунктир поверх (ширина 2, `stroke-dasharray: 2 14`, `stroke-dashoffset` анимируется CSS `@keyframes` от 0 до −64 за 1.6 с, белый .5): «течёт».
- Толщина основной линии зависит от потока: `2 + 3 × (поток по связи / максимальный поток)`. Поток по связи = поток узла-источника, поделённый на число его исходящих. Поток источника трафика = его доля в `L` (основной источник 40%, остальные поровну).
- Частицы-клиенты: на каждой `flow`-связи 1–3 кружка радиуса 2.5 цвета акцента с мягким свечением (`filter: drop-shadow`), движение через SMIL `<animateMotion dur="2.4s" repeatCount="indefinite" begin="-{случайный сдвиг}s"><mpath href="#edge-id"/></animateMotion>`. Число частиц ∝ потоку. Всего на холсте не больше 80 частиц.
- Маркер потерь (только «Как сейчас»): на середине связи от точки входа красная «капля» 14 px, рядом подпись «теряется ≈ 30% заявок». Часть частиц на этой связи (в доле `leak0`) уходит не к цели, а вниз и гаснет: отдельные `<animateMotion>` по короткому пути, отходящему от середины связи вниз на 40 px, с анимацией `opacity` 1 → 0.
- Петля возврата (`kind: 'loop'`): толстая дуга под всей схемой от правого края колонки `retain` к левому краю колонки `entry`, путь `M xr yb C xr yb+160, xl yb+160, xl yb`, где `yb` — низ самой высокой колонки + 40. Цвет — градиент зелёного `#6be0a8` → акцент, пунктир крупнее, частицы идут справа налево. Посередине дуги подпись «Клиент возвращается и приводит друзей». Если в варианте нет блоков `retain`, петли нет, а на её месте бледный пунктир с подписью «Клиенты не возвращаются» (только в «Как сейчас» и в вариантах, где пользователь удалил все `retain`).
- Связи данных (`kind: 'data'`): тонкая (1 px) пунктирная `4 6` линия, цвет `#6bd5e0` .5, без частиц.
- Выделенная связь: ширина +2, кнопка «×» на середине для удаления.

## 3. Взаимодействие

Всё на Pointer Events (`pointerdown/move/up`, `setPointerCapture`), одинаково для мыши, пера и тача.

| Действие | Мышь | Тач | Клавиатура |
| --- | --- | --- | --- |
| Сдвиг холста | Перетаскивание по пустому месту, или пробел + перетаскивание, или колесо без модификаторов (по вертикали; с Shift — по горизонтали) | Один палец по пустому месту | Стрелки, когда фокус на холсте, а не на узле (шаг 40 px) |
| Масштаб | Ctrl/Cmd + колесо, щипок трекпада (`wheel` с `ctrlKey`) к точке курсора | Два пальца | `+` / `−` / `0` (100%) / `F` (вписать) |
| Выделить узел | Клик | Тап | Tab по узлам в порядке этапов, Enter открывает инспектор |
| Двигать узел | Перетаскивание (порог 4 px) | Долгое нажатие 400 мс, затем перетаскивание | Стрелки (шаг 8 px, с Shift 40 px) |
| Создать связь | Тянуть от выходного порта к узлу (подсвечиваются допустимые цели) | То же после долгого нажатия на порт | В инспекторе блока: «Соединить с…» и список |
| Удалить | Delete / Backspace на выделенном | Кнопка в инспекторе | Delete |
| Множественный выбор | Shift + клик, рамка выделения при перетаскивании с Shift по пустому месту | — | — |
| Добавить из библиотеки | Перетащить карточку на холст | Кнопка «+» на карточке | Enter на карточке |
| Отмена | Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z | Кнопки тулбара | — |

Детали:
- Масштаб от 0.35 до 1.8. Плавность: целевое значение интерполируется за 120 мс.
- Привязка узлов к сетке 8 px. При перетаскивании узла рядом с другим узлом той же колонки показываются направляющие выравнивания (тонкие линии акцента), привязка по центру или краю с порогом 6 px.
- Перетаскивание узла в другую колонку разрешено (это пользовательская схема), но узел сохраняет свой этап по каталогу и цвет. Если узел оказался левее этапа-источника своих входящих связей, связь рисуется петлёй назад без ошибок.
- Допустимые цели связи: любой узел, кроме самого себя и уже связанного тем же направлением. Связь `retain → entry/traffic` автоматически получает `kind: 'loop'`.
- Каждая правка помечает вариант `edited: true`, пишет шаг в историю (снимок `nodes/edges` варианта), пересчитывает экономику с дебаунсом 120 мс и автосохраняет документ с дебаунсом 600 мс.
- Перетаскивание из библиотеки: при входе карточки на холст под курсором появляется «призрак» узла (полупрозрачный), колонка подходящего этапа подсвечивается, подпись «Отпустите, чтобы добавить».

## 4. Мини-карта

160 × 100 в правом нижнем углу холста, фон `rgb(0 0 0 / .35)`, радиус 10. Узлы — прямоугольники цвета этапа, рамка видимой области — белая .6. Клик и перетаскивание по мини-карте двигают вид. На мобильных скрыта.

## 5. Производительность

- До 60 узлов и 120 связей при 60 fps на MacBook Air M1 и 30+ fps на iPhone 12.
- Во время перетаскивания узла пересчитываются только связи этого узла, в одном `requestAnimationFrame`.
- Связи не пересоздаются: при изменении меняется атрибут `d`, элементы `<path>` переиспользуются по id связи.
- `will-change: transform` только у мира и у перетаскиваемого узла, снимается после окончания.
- `backdrop-filter` отключается у узлов при масштабе < 0.6 и во время пана (класс `.is-panning` на сцене).
- Частицы ставятся на паузу (`svg.pauseAnimations()`), когда холст вне экрана (`IntersectionObserver`) или вкладка скрыта (`visibilitychange`).

## 6. Анимации

Все длительности и кривые — CSS-переменные в начале `growth-map.css`:

```css
--gm-ease: cubic-bezier(.22, 1, .36, 1);     /* выход */
--gm-spring: cubic-bezier(.34, 1.56, .64, 1); /* лёгкий перелёт */
--gm-fast: 160ms; --gm-mid: 320ms; --gm-slow: 640ms;
```

### 6.1. Появление схемы (после анализа и при открытии сохранённой)

Узлы по порядку этапов, затем по вертикали: `opacity 0 → 1`, `transform: translateZ(-500px) rotateX(25deg) → none`, 640 мс `--gm-ease`, задержка 40 мс × индекс (максимум 1.2 с общей задержки). Связи: `stroke-dasharray = длина`, `stroke-dashoffset: длина → 0`, 500 мс, стартует, когда появились оба конца. Петля возврата рисуется последней, 900 мс.

### 6.2. Переключение вариантов (морфинг)

Метод FLIP:
1. Запомнить прямоугольники узлов текущего варианта по ключу `block` (+ порядковый номер для повторов).
2. Отрисовать новый вариант.
3. Узлы, которые есть в обоих: анимация из старой позиции в новую, 480 мс `--gm-ease`.
4. Новые: `scale .6 → 1`, `opacity 0 → 1`, `--gm-spring`, 420 мс, после завершения перемещений; над узлом на 3 с метка «новое».
5. Исчезающие: `scale 1 → .8`, `opacity → 0`, 220 мс, до перемещений.
6. Связи: исчезающие гаснут, новые прорисовываются после появления узлов.
7. Счётчики экономики накручиваются 400 мс.
8. При переходе в «Автопилот» по сцене один раз проходит мягкая золотая волна (радиальный градиент, расширяется от центра за 900 мс, `opacity .25 → 0`).

### 6.3. Режим «Объём»

Кнопка «Объём» переводит сцену в изометрический 3D-обзор:
- мир получает `transform: translate(...) scale(...) rotateX(55deg) rotateZ(-35deg)`, переход 900 мс `--gm-ease`;
- каждый узел поднимается `translateZ(var(--lift))`, где `--lift` = 12 px × (порядок этапа + 1): схема поднимается ступенями слева направо, как лестница роста;
- толщина узлов (`::after`) увеличивается до 14 px, тени ложатся на «пол» (отдельный размытый прямоугольник под каждым узлом в плоскости мира);
- связи остаются на полу и продолжают течь;
- пан мышью вращает сцену: горизонтальное движение меняет `rotateZ` в пределах −60…−10°, вертикальное — `rotateX` в пределах 40…65°;
- правка отключена, клик по узлу открывает инспектор только для чтения;
- выход кнопкой «Выйти из 3D» или Esc, обратный переход 700 мс.

### 6.4. Сцена анализа

Описана в 01-product-ux.md, раздел 7. Технически: оверлей `.gm-hud` поверх холста; сканирующая линия — `div` высотой 2 px с градиентом и тенью-свечением, `translateY` от 0 до высоты сцены за 1.2 с, повтор 3 раза; шаги — список с `aria-live="polite"`.

### 6.5. prefers-reduced-motion

При `matchMedia('(prefers-reduced-motion: reduce)')`:
- нет частиц, нет течения пунктира, нет наклона за курсором, нет золотой волны;
- появление и морфинг — только `opacity` 150 мс;
- сцена анализа пропускается;
- «Объём» включается без перехода, вращение отключено.

## 7. Доступность

- Холст — `role="application"` только у `.gm-stage` с `aria-roledescription="схема"` и подсказкой `aria-describedby` (скрытый текст с управлением с клавиатуры).
- Узел: `role="listitem"`, `aria-label="{Этап}: {Название}. {Эффект}. Связан с: {список}"`.
- Кнопка «Показать списком» в тулбаре (и всегда для скринридеров) рендерит текущий вариант как упорядоченный список по этапам с перечислением связей. Это полноценная альтернатива холсту.
- Все цвета текста на сцене проходят контраст 4.5:1 на `--night`.
- Фокус виден: кольцо 2 px акцента со смещением 3 px.
- Изменения экономики объявляются в `aria-live="polite"` не чаще раза в 2 с: «Ускорение: выручка 1,2 млн ₽ в месяц, прирост 62%».

## 8. Иконки

`docs/assets/growth-map/gm-icons.js` экспортирует `window.DevlarionGM.icons = { id: '<svg …>' }`. Стиль: viewBox 24, `fill="none" stroke="currentColor" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"`, как у `docs/assets/icons/*.svg`. Знаки брендов (`telegram`, `vk`, `avito` если есть в Simple Icons, `instagram`, `youtube`) — заливкой `currentColor` из Simple Icons. Нужный набор: все значения поля `icon` в каталоге (03-catalog.md) плюс иконки сфер плюс иконки тулбара (`undo`, `redo`, `layout`, `fit`, `cube`, `minus`, `plus`, `list`, `more`, `download`, `link`, `cabinet`, `close`). Около 75 иконок. Существующие файлы из `docs/assets/icons/` переиспользовать, где подходят.
